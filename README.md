# 大學物理筆記 - Typst 版本

這是一個使用 Typst 排版系統編寫的大學物理筆記項目，包含了物理學的學習筆記和例題解析。

## 項目簡介

本項目是作者的大學物理學習筆記，使用 Typst 進行排版，具有以下特點：

- **美觀的數學公式**：Typst 提供優秀的數學公式排版能力
- **清晰的結構**：章節分明，內容組織有序
- **豐富的例題**：包含大量物理例題和詳細解答
- **圖文並茂**：配合圖表幫助理解物理概念

## 項目結構

```
typst/
├── physic/              # 物理筆記目錄
│   ├── 14/             # 第14章
│   │   ├── 14.typ      # Typst 源文件
│   │   ├── 14.pdf      # 生成的PDF文件
│   │   └── img/        # 圖片資源
│   └── 15/             # 第15章 - 導體
│       ├── 15.typ      # Typst 源文件
│       ├── 15.pdf      # 生成的PDF文件
│       └── img/        # 圖片資源
├── typst.code-workspace # VSCode 工作區配置
└── README.md           # 項目說明文件
```

## 使用說明

### 編譯 Typst 文件

要編譯 Typst 文件為 PDF，可以使用以下命令：

```bash
typst compile physic/15/15.typ
```

### 查看筆記

- 直接查看 PDF 文件：`physic/15/15.pdf`
- 編輯源文件：`physic/15/15.typ`
- 查看圖片資源：`physic/15/img/`

## 技術棧

- **數學公式**：Typst 內置數學引擎
